JoaoAlmeidaTracker

Purpose: 100% free GitHub Actions bot that tracks Portuguese cyclist João Almeida's race results from ProCyclingStats. Runs every 2 hours, prevents duplicate alerts with state files committed to the repo.
PythonGitHub Actionsrequests + BeautifulSoupTelegram Bot APIZero infrastructure cost

Workflow

Key Workflows

Automated Tracking (every 2h)
GitHub Actions cron trigger → Python script fetches ProCyclingStats profile → parses latest race results → compares with state.json stored in repo → if new result found: sends Telegram alert and commits updated state.json.
Zero-Cost Architecture
No server, no database, no Docker — runs entirely on GitHub Actions free tier. State persistence uses committed JSON files instead of a database.
