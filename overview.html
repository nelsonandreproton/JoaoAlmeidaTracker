João Almeida Tracker

Python 3.11 BeautifulSoup + cloudscraper GitHub Actions Telegram Bot API

1. What this project does

Purpose

Tracks professional cyclist João Almeida's race results from ProCyclingStats. Every 2 hours, checks if he finished a stage race GC or one-day race today and sends a Telegram notification. State persisted as a git-committed JSON file to prevent duplicate notifications across GitHub Actions runs.

3. Reliability

GitHub auto-disables a schedule-triggered workflow after 60 days with no commit to the repo — a commit-on-change-only bot can go silently idle for a full season with no error. Two safeguards close this gap:

scheduler.ymlevery run
→
last_run.txtUTC timestamp, committed unconditionally
→
healthcheck.ymldaily 08:30 UTC
→
Telegram alertif stale >6h
